# H05 中性立绘视觉说明

沿已确认 H02 工笔样板。两人使用同样的细墨褐轮廓、矿物色感与轻纸纹；黛玉清瘦含蓄，悟空为明确猴相、金箍、赭金短衣与朱砂腰带。禁止退回 H03 几何占位画风。

本批只有两张中性母版，preview.png 为浅底／深底透明边检查板，不是场景合成或最终页面。人物在游戏中位于地面层之后、前景之前；阴影由程序绘制，不烘焙进 PNG。

每张 768×1024 RGBA，人物外有真实 alpha=0，附 sRGB ICC。assets.csv 的脚底是实测值：在实际查看鞋履位置后，以 alpha≥128 的最下方鞋履接触带测得 x 中点与 y，再归一化保留三位小数。不是场景落点建议，也不是游戏试放结果。

正式场景中的显示比例与落点随 H07/H08 真实图层合成另给；现有 H03 的占位参数不直接沿用。人物全身、头饰、花锄、金箍棒、尾部与鞋履均须保留，不用非等比拉伸凑高。

后续表情严格从本母版编辑，仅局部改变脸，身体、服饰、道具、轮廓与脚底不变。A 先验中性并回试放意见；B 可独立继续正式剧情和表情处理。未验证：游戏内光效、双角色站位、前景遮挡、手机显示与表情切换。
