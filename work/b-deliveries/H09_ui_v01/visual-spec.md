## 4 场景裁切、缩放与镜头边界

**必须**：两场景全图1600×900使用同一等比变换；人物和落点共享该变换。默认完整显示、居中留边，不用cover裁掉头饰、山树或脚底；禁止非等比拉伸。画卷框是装饰，不替换或重复背景图。

现有图层无额外出血，基线镜头平移边界为 **x=0、y=0**，场景整体不平移。开卷可以用遮罩逐步显露完整画境，不把图片拉成长条。若A希望轻微视差，只能在验证不露底／不丢关键形体后，对装饰前景作极小变化；默认关闭，不为动效再扩范围。

手机横屏同样保留完整画境。竖屏允许画境在上、操作区在下，并滚动阅读；不把整个桌面UI随16:9图片一起缩到不可读。不得用宽高100%强行塞满手机容器。

## 5 字幕、选择栏与控件

以下为H01硬边界，坐标按1600×900：

- 阅读留白：y=720–900，保持浅、静，不塞枝叶或主角。
- 字幕、提问和两项选择：x=96–1504、y=720–873。开场／提问选择／终章按阶段切换，不一屏堆全部文字。
- 常驻控制：x=1152–1504、y=36–108。框饰在控件下，建议控件避开边饰横杆，使用该区偏下部分。
- 人物保护框：x=288–1312、y=108–720；脚底建议带x=400–1200、y=630–693。

卷轴底部有细边饰，正文与按钮留足下边距，优先放在阅读区y=732–836内；若当前正文、两按钮与装饰无法同时清楚放下，将阅读控件整块移到场景下方。这是排版适应，不改故事数据。

选择栏只提供两个角色、两个场景，在选择阶段用现有阅读区或场景下方排布。正式界面不照搬H03大块米色面板、厚矩形边框及卡片层级。可调建议：用墨色短标题、轻纸面和细线控件；两选项等权，激活以淡青绿／细墨线标识。不要一项实心深绿、一项淡描边来暗示正确答案。

按钮与落点目标至少44×44 CSS px，点击范围可比可见描边大；文字使用页面独立尺寸，不随场景缩放变成小字。只保留既定场景／角色选择、字幕、双选项、静音（若有音）、重玩及结果预览／下载。版本号和源文件状态放交接资料，不放在主画境抢视觉。

## 6 字体、颜色与留白

推荐标题与故事采用可读的中文宋体气质，如Noto Serif SC／思源宋体；按钮可同族较清晰字重，避免用花体毛笔字排长正文。A负责合法字体文件与完整H04文本的字库覆盖，不能直接以旧H03子集覆盖全部新人物／场景。本示意图使用系统宋体绘制参考，不是新字体资产交付。

可调整起点：桌面正文20–24 CSS px、行高约1.65–1.8；标题28–36px。手机阅读区正文保持至少18px左右，并按设备实测调节；不要因一屏放不下而持续缩字。选项与正文之间留一行以上空气，读者先看人物、再看事件、再作选择。

色彩建议：纸底#F4EBDD，墨褐#342F2A，正文次级#4A4640，青绿#3F6C61与#A8C3B0，桃粉#D995A6。以真实PNG相对关系为准，不要求每像素相同色值。不加全页脏黄滤镜或强阴影。paper_texture自身alpha已乘12%，最大28，铺在程序米白底上即可，不要再当不透明大底图；无缝平铺未验证，按整幅使用。

## 7 入场、视差与结局反馈

必须保证所有反馈可中断、可重玩清理，且不依赖实时AI。建议：角色以约180–250ms淡入，缩放中心固定脚底；静止轻呼吸不超过约1%，不挪脚；减少动态时关闭这些装饰，故事仍完整。

四个既定效果：petal_fall约2秒、petal_gather约1.5秒、gold_spark约1.5秒、clone_echo约1秒。聚花朝实际角色脚边，金点靠近人物，残影复用当前立绘、低alpha、按安全空间收拢；花瓣／残影不挡面部或按钮。八结局对应表见ending-effects.csv，所有ID来自H01；B已检查映射，实际渲染与时序由A／Claude接入验证。不得把静态图或效果指令称为实时AI或已实装动画。
