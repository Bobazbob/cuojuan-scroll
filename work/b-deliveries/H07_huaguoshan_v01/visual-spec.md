# 花果山本批视觉实现说明

以scene-notes.md为本批位置、层序、遮挡、比例和镜头边界的权威说明。完整实际合成见preview.png与preview_wukong.png，标注见annotated-preview.png。

必须遵守：H02工笔宣纸画风；完整等比画境；角色PNG不拉伸；按实测脚底锚点定位；ground→角色→front；前景不挡脸及UI；底部和右上安全区；来源图不烘焙正文。H03几何人物／网页／结果卡已被用户排除，不作视觉模板。

可调整建议：人物显示高度与B候选落点可在H01安全框及实际平地内由A试放校准，保留差异记录。基线为黛玉504px、悟空480px，落点分别(0.625,0.750)、(0.750,0.750)，不是强制的新接口字段。

本批所有图层由图像工具实际绘制；辅助代码只做精确画幅、透明边清理、登记与真实合成／标注。没有使用程序几何图替代正式山水或角色。四图均RGBA/sRGB ICC，底层alpha全255；上层空白alpha=0。完整视觉规范和八结局映射随H09汇总。

动画建议：角色从alpha0至1平缓显现，以脚底为缩放中心；停留轻呼吸幅度约1%，不移动脚底。不要用自动大幅缩放或全场景横移破坏构图。实际动效和手机尚未验证。
