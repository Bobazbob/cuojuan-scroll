# H06 六张角色立绘视觉说明

本包包含最终中性母版和各自两表情：黛玉 neutral／happy／upset，悟空 neutral／happy／angry。全部沿 H02 工笔样板，人物造型与 H05 画风不变。

按 A 的 H05 局部反馈，仅移除离可见轮廓超过3px、alpha<16的远处残留；主体 alpha≥16 完全不变，实测脚底不变。两张 neutral 本包替代 H05 v01 的透明背景版本；H05 原包保留。

四表情确由图像模型编辑获得。为防止模型重绘身高和道具，编辑结果仅注册并合成到母版面部内区；不是用代码画表情。每角色三张的完整alpha、面部区域之外像素逐像素一致，头顶、身体轮廓、花锄／金箍棒、衣服和脚底漂移为0px。alignment-check.json 给出面部多边形和注册结果；face-comparison.png 展示真实表情差异。

立绘768×1024 RGBA/sRGB ICC。脚底锚点：黛玉(0.499,0.980)，悟空(0.500,0.979)，均由鞋履实际接触带测量；不是场景落点。人物以脚底定位，置于ground之后、front之前；阴影交程序。场景坐标与显示比例由H07/H08正式合成给出，仍需A在页面内实测。

preview.png 是三表情完整角色检查板；sources 是图像模型编辑原件，不进入运行资产。原件尺寸与身体局部可能漂移，正式交付以characters下锁定母版的六张PNG为准。

已验证静态一致性与透明边；未验证游戏切换、前景遮挡、手机大小和效果播放。
