# 给 Claude 的任务

你接手同一个《错卷》工程的正式视觉与交互。先从 B 已确认的样板、正式花果山图层、正式黛玉立绘、分层重组图与 visual-spec 读取视觉依据。H03 只用于核对功能顺序。

先完成“黛玉来到花果山”一个正式场景。按 README 运行工程，阅读 `docs/core-api.md`、`docs/h01-v02/contract-v1.md`、`asset-library/README.md`。从 `src/core/index.ts` 调用现有引擎和资源加载器，使用原有数据、ID 和状态机驱动选择、放置、剧情、结局与重玩。可运行的接口示例是 `core-demo.html`。

- 顺序使用远景、中景、地面、人物与前景。对照实测人物脚底与场景落点保持贴地。校验衣裙、发饰和道具完整，避免拉伸、随意裁切或用程序形状代替正式美术。
- 当前场景素材无出血，整景按原始 16:9 画面定镜。只有确认装饰前景变化不露底、不裁内容时才做微量视差。字幕、控件和选项固定在独立 UI 层，遵守 v02 的安全区。在窄窗口内保持可读、可点。
- 卷轴整幅等比使用。上缘装饰横条与右上安全框交在 y=36–58，下缘与阅读框交在 y=841–864（原图像素）。控件放在剩余净区并使用独立衬底，空间不足时移离画面，装饰层不接收点击。
- 使用引擎返回的立绘表情、层级 ID 和效果指令。效果应服从 B 的画面基调；重玩时用本局 AbortSignal 清理视觉层副作用。开发中报告哪些效果已实装。
- 实际启动并操作开卷、放置、两条分支和重玩。交付可运行页面、截图和 B 能复核的位置。等待 B 对这个正式场景验收，通过后再扩展其他组合、正式卡面和手机布局。
